Git Exercise Project

This project is created to practice Git and GitHub workflows.

Project Structure:
- Feature branches
- Git-flow workflow
- Version control best practices

Features:
- Analytics tracking module
- Utility functions (date, string, email)
- Logger module with multiple log levels
- Bug fixes for validation and memory management

Setup Instructions:

Installation:
Clone the repository and navigate to the project directory

Running the Application:
Open main.txt to see application entry point

Version History:
- v1.1.0: Added analytics and bugfixes
- v1.0.0: Initial release
